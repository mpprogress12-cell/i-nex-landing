# I-NEX лендінг — деплой на Netlify

## Що в комплекті

```
/
├── index.html          ← головна (вебінар + реєстрація)
├── login.html          ← вхід для учасників
├── thank-you.html      ← сторінка подяки після реєстрації
├── css/styles.css      ← брендовий стиль (navy + orange, Montserrat/Lato/Poppins)
├── js/main.js          ← меню, валідація форм, банер cookies
├── netlify.toml        ← конфіг + безпекові заголовки
└── README_DEPLOY.md    ← цей файл
```

> Додай ще `og-image.jpg` (1200×630) у корінь — для гарного прев'ю у месенджерах.

## Деплой за 2 хвилини

**Варіант A — перетягуванням (найшвидше):**
1. Поклади всі файли в одну папку, збережи структуру (css/, js/ — підпапки).
2. Відкрий https://app.netlify.com/drop
3. Перетягни всю папку у вікно. Готово — сайт онлайн.

**Варіант B — через Git (рекомендовано для оновлень):**
1. Залий папку в репозиторій GitHub.
2. Netlify → Add new site → Import from Git → обери репозиторій.
3. Publish directory: `.` (корінь). Build command: лишити порожнім.

## Форма реєстрації — працює БЕЗ бекенду

Форма підключена до **Netlify Forms** (`name="registration"`, `data-netlify="true"`).
Після деплою всі заявки збираються автоматично.

**Щоб заявки приходили Марії на пошту:**
1. Netlify → твій сайт → **Forms** → форма `registration`.
2. **Settings → Form notifications → Add notification → Email notification**.
3. Email: `mariia.halai@gmail.com`. Збережи.
4. Тепер кожна заявка дублюється листом + видно в дашборді Netlify.

Після надсилання користувач потрапляє на `thank-you.html`.

## Вхід для учасників (login.html)

Зараз це **UI-заглушка** (реального входу нема — портал ще не існує).
Коли буде портал учасників, для справжньої авторизації:
- увімкни **Netlify Identity** (Netlify → Identity), або
- підключи власний бекенд / сервіс авторизації.

> ⚠️ Поки порталу нема — посилання «Вхід» можна тимчасово прибрати з меню (рядок у `index.html` з `login.html`), щоб не плутати відвідувачів.

## Банер cookies

Показується один раз, вибір запам'ятовується у браузері. «Дізнатися більше» зараз веде на секцію сайту — заміни на сторінку політики конфіденційності, коли вона буде.
