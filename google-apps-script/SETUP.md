# I-NEX AI — Налаштування Google Apps Script для форми реєстрації

Цей документ описує, як створити Google Sheet, підключити Google Apps Script (`Code.gs`), розгорнути Web App та інтегрувати форму з лендінгом на Netlify.

---

## 1. Створіть Google Sheet

1. Перейдіть у [Google Sheets](https://sheets.new) та створіть нову таблицю.
2. Дайте таблиці зрозумілу назву, наприклад: **"I-NEX AI — Реєстрації"**.
3. Залиште перший аркуш порожнім — заголовки колонок створяться автоматично при першій реєстрації.

> Аркуш із реєстраціями називатиметься **`Реєстрації`** (константа `SHEET_NAME` у `Code.gs`).

---

## 2. Відкрийте редактор Apps Script

1. У Google Sheet натисніть **Розширення → Apps Script**.
2. Відкриється редактор Google Apps Script із порожнім файлом `Code.gs`.

---

## 3. Вставте код

1. Видаліть увесь вміст стандартного файлу `Code.gs`.
2. Скопіюйте повний вміст файлу [`Code.gs`](./Code.gs) з цього репозиторію.
3. Вставте його в редактор Apps Script.
4. Натисніть **Зберегти** 💾.

---

## 4. Налаштуйте змінні (опціонально, але рекомендовано)

У `Code.gs` знайдіть блок **CONFIGURATION**:

```js
var SHEET_NAME = "Реєстрації";
var ADMIN_EMAIL = "your-email@example.com";
```

- `SHEET_NAME` — назва аркуша, куди записуватимуться заявки.
- `ADMIN_EMAIL` — email для повідомлень про нові реєстрації. Замініть `your-email@example.com` на свою адресу.

> Якщо email залишити без змін (`your-email@example.com`), повідомлення не надсилатимуться — це безпечно.

---

## 5. Ініціалізуйте заголовки колонок

1. У редакторі Apps Script оберіть функцію **`initSheetHeaders`** у випадаючому списку поруч із кнопкою ▶️.
2. Натисніть **Запустити**.
3. Надайте дозволи на доступ до таблиці, якщо запитає.

Після запуску в аркуші "Реєстрації" з'являться такі колонки:

| Час реєстрації | Прізвище та ім'я | Назва компанії | Посада | Email | Номер телефону | Сфера діяльності компанії | Участь з колегою |
|---|---|---|---|---|---|---|---|

---

## 6. Розгорніть Web App

1. У редакторі Apps Script натисніть **Розгорнути → Нове розгортання**.
2. У вікні, що відкрилось, натисніть **Тип → Веб-застосунок**.
3. Заповніть поля:
   - **Опис**: `I-NEX AI registration endpoint`
   - **Виконувати як**: `Мене`
   - **Доступ**: `Будь-хто`
4. Натисніть **Розгорнути**.
5. Підтвердьте дозволи, якщо з'явиться вікно авторизації.
6. Скопіюйте **URL веб-застосунку** — це адреса, яку потрібно вставити у форму на лендінгу.

### URL виглядатиме так:

```
https://script.google.com/macros/s/ВАШ_ІДЕНТИФІКАТОР/exec
```

> ⚠️ Зберігайте цей URL у секреті — будь-хто, хто його знає, може надсилати заявки.

---

## 7. Встановіть дозволи

Під час першого розгортання Google запросить дозволи:

- Доступ до Google Sheets (читання/запис).
- Доступ до Gmail/Email (для надсилання сповіщень адміністратору).

Натисніть **Дозволити** в усіх вікнах. Якщо з'явиться попередження "Ця програма не перевірена":

1. Натисніть **Додатково**.
2. Потім **Перейти до проєкту (небезпечно)**.
3. Надайте дозволи.

---

## 8. Протестуйте роботу

1. Відкрийте файл [`test-form.html`](./test-form.html) у браузері.
2. Вставте URL Web App у перше поле.
3. Заповніть решту полів та натисніть **Відправити тестову заявку**.
4. Перевірте Google Sheet — новий рядок має з'явитися в аркуші `Реєстрації`.

> Якщо тест проходить успішно, але дані не записуються — перевірте, чи ви запускали `initSheetHeaders` і чи є аркуш з назвою `Реєстрації`.

---

## 9. Інтеграція з лендінгом на Netlify

У вашому HTML/JS на лендінгу використовуйте такий код відправки форми:

```html
<form id="registration-form">
  <input name="fullName" placeholder="Прізвище та ім'я" required>
  <input name="company" placeholder="Назва компанії" required>
  <input name="position" placeholder="Ваша посада" required>
  <input type="email" name="email" placeholder="Email" required>
  <input type="tel" name="phone" placeholder="Номер телефону" required>
  <input name="industry" placeholder="Сфера діяльності компанії">
  <input name="colleague" placeholder="Чи плануєте участь з колегою?">
  <button type="submit">Зареєструватися</button>
</form>

<script>
  const SCRIPT_URL = 'https://script.google.com/macros/s/ВАШ_ІДЕНТИФІКАТОР/exec';

  document.getElementById('registration-form').addEventListener('submit', async (e) => {
    e.preventDefault();
    const formData = new FormData(e.target);

    try {
      const response = await fetch(SCRIPT_URL, {
        method: 'POST',
        body: new URLSearchParams(formData),
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' }
      });

      const result = await response.json();

      if (result.status === 'success') {
        alert(result.message);
        e.target.reset();
      } else {
        alert('Помилка: ' + result.message);
      }
    } catch (err) {
      alert('Не вдалося відправити форму. Спробуйте пізніше.');
    }
  });
</script>
```

### Важливі нюанси для Netlify

- Скрипт повертає заголовки CORS (`Access-Control-Allow-Origin: *`), тому запити з Netlify проходитимуть без помилок.
- Використовуйте `application/x-www-form-urlencoded` або `application/json` — `Code.gs` підтримує обидва формати.
- Зберігайте URL Web App у змінних оточення Netlify або в окремому JS-файлі, який не потрапляє в публічний репозиторій.

---

## 10. Оновлення скрипта

Якщо ви вносите зміни в `Code.gs`:

1. Збережіть зміни.
2. Натисніть **Розгорнути → Керування розгортаннями**.
3. Знайдіть активне розгортання та натисніть **Олівець ✏️** → **Версія → Нова версія**.
4. Натисніть **Розгорнути**.

URL Web App залишиться тим самим.

---

## 11. Вирішення типових проблем

| Проблема | Причина / Рішення |
|---|---|
| `CORS error` у браузері | Переконайтесь, що Web App розгорнуто з доступом "Будь-хто". |
| `Invalid JSON payload` | Перевірте, чи правильно формується тіло запиту на фронтенді. |
| Пусті поля в таблиці | Перевірте, що `name` полів форми відповідають ключам у `Code.gs`. |
| Не надходять листи адміну | Перевірте `ADMIN_EMAIL` та квоти Gmail (у безкоштовному акаунті — 100 листів/день). |
| `You do not have permission` | Переконайтесь, що Web App виконується від вашого облікового запису з доступом до таблиці. |
